    Field guide (works with no internet)

    1. Start up

    1. Antennas on before power. Both radios plugged into the USB hub; the hub into the tablet.
    2. Open the MeshCore app on the tablet and connect to the CAIRN companion by Bluetooth (this is for chatting).
    3. Open this page and press Connect radio, choose the radio's USB port (this is for the station view and the log).
    4. The page sets the radio's clock from the tablet, loads the journal from the radio, and shows REACHABLE once a repeater is heard.

    2. Check in

    • Press SEND CHECK-IN. The radio sends LC-xxxxxxxx Reporting at: latitude,longitude. With no GPS fix it says no GPS fix.
    • Every CAIRN station that hears it lists you on its Check-ins page.

    2b. Send and read messages

    • Open Chat. Pick a channel (left) or start a direct message, type in the box, press Send or Enter. Messages are 140 characters at most.
    • Replies appear in the same conversation. A red number shows messages you have not read.
    • You can also chat in the MeshCore app over Bluetooth; both views show the same traffic.

    3. Reading the Station page

    • REACHABLE (green): a repeater is heard now. NO REPEATER HEARD (red): move higher or toward the last usable repeater shown.
    • Nearby lists repeaters, room servers and companions with signal strength and how recently they were heard.
    • Log holds everything the radio heard. It is saved on the radio and on this tablet. Download it after the event.

    4. Disaster mode

    Press DISASTER on the Station page. Screens turn off sooner, quiet hours are off, and silent repeaters are marked stale sooner.

    5. If something fails

    • Page will not connect: use Chrome (version 148 or newer on Android). Unplug and replug the radio. Close other apps using USB.
    • No repeater heard: check the antenna; go higher, outside, away from metal. Wait 10 minutes for adverts.
    • Keyboard broke: use the ⌨ button for the on-screen keyboard.
    • Hub noise: keep the antenna away from the USB hub and cables.

    6. Commands (typed in the MeshCore app or a serial console)

    • cairn station ID and journal size   cairn id   cairn ok [channel] send a check-in
    • cairn say <channel> <text> send a channel message   cairn dm <key> <text> direct message   cairn chans list channels
    • cairn mode disaster / cairn mode normal   cairn dump send the journal   cairn clear yes erase it
    • cairn time <seconds since 1970> set the radio's clock   nova NOVA status

    7. Kit checklist

    • ☐ Tablet, keyboard, stylus   ☐ USB hub   ☐ CAIRN companion radio + antenna
    • ☐ Repeater + antenna   ☐ 2 power banks (charged)   ☐ Solar panel + cable
    • ☐ Spare cables   ☐ Paper copy of this guide   ☐ Offline map loaded for your area

    A radio mesh is a backup. It is not a replacement for 911, a phone or a satellite messenger, and it only works if other radios or repeaters are in range. This is ALPHA software.
