# LODESTAR CAIRN

**ALPHA** field-station firmware by FEAR REACTIVE for the Heltec WiFi LoRa 32 V4 **R2**, built on [MeshCore](https://github.com/meshcore-dev/MeshCore) and LODESTAR NOVA.

CAIRN is for a MeshCore kit that has to keep working, and keep records, when things go wrong: a tablet, a companion radio, a repeater and a power bank in one case. This README is a stub while the first build is tested.
