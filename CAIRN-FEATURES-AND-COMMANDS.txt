LODESTAR CAIRN - FEATURES AND COMMANDS (Ver. 1.0.4, ALPHA)
By FEAR REACTIVE. For the Heltec WiFi LoRa 32 V4 R2 (not the R8).
ALPHA: tested on a PC and in a browser with practice data, not yet on real hardware.

WHAT CAIRN IS
A MeshCore companion radio (NOVA, plus extras) for a crisis field kit. It keeps a journal of everything it hears,
has a station ID, sends a one-button check-in, and feeds a tablet dashboard that works with no internet.

FEATURES
- Station ID: LC- plus 8 letters/digits from the last 5 bytes of the radio's public key. Random at first boot
  (MeshCore makes the key), never changes, survives reboot. Not checked against any list (offline). Duplicate odds:
  about 1 in 2.2 million for 1,000 stations in range.
- Check-in: "LC-xxxxxxxx Reporting at: <lat>,<lon>" or "... Reporting at: no GPS fix". Sent to a channel (default 0).
- Journal: every message (channel, direct, room, reply), every advert (repeater, companion, room server, sensor)
  with signal and hops, every check-in sent, every boot. Saved on the radio (/cairn.log, rotated at 192 KB to
  /cairn.1) and copied to the tablet. Export CSV or JSON lines.
- Disaster mode: screen off sooner, quiet hours off, stale repeaters marked sooner. Back to normal with one press.
- Station page: REACHABLE / NO REPEATER HEARD, best repeater, last usable repeater, last place with coverage.
- Nearby: repeaters, room servers, companions: SNR, hops, age, distance and compass direction.
- Chat: send and read messages from the dashboard (the Chat tab). Pick a channel or a person, type up to 140
  characters, press Send. Replies show in the same conversation. Direct messages need the person to be in the radio's
  contact list. You can still chat in the MeshCore app over Bluetooth at the same time.
- Check-ins roster: who reported, when, where, overdue flag, tap to mark NEEDS HELP.
- Map: offline vector maps, your position, nodes, check-ins, last coverage point.
- Power: radio battery (if a LiPo is fitted), tablet battery, manual power-bank timers.
- Guide: offline field guide, printable.
- No on-screen keyboard unless you tap the keyboard icon.
- OLED screen: boot splash with the CAIRN emblem (a guiding star over a cairn of stones), and a CAIRN STATION screen
  (the first page after Home) showing the ID, journal size and time since the last check-in. Press Enter (or hold
  the button on a one-button board) on that screen to send a check-in.
- Everything NOVA does still works.

DASHBOARD (browser page, Chrome 148+ on Android, or recent Chrome/Edge on a computer)
Tabs: Station, Nearby, Check-ins, Log, Map, Power, Guide. "Practice" fills it with made-up data.
Needs the BLUETOOTH firmware build: the USB port is used by the dashboard.

COMMANDS (type in the MeshCore app's command box for your radio, or in a serial console)
  cairn                      status: version, ID, journal size
  cairn id                   print the station ID
  cairn ok [channel]         send a check-in now (channel 0-39, default 0)
  cairn say <ch> <text>      send a message to channel <ch> (0-39), 140 characters at most
  cairn dm <key12> <text>    send a direct message to the contact whose key starts with these 12 hex characters
  cairn chans                list the radio's channels (the dashboard asks for this)
  cairn mode disaster        disaster mode on
  cairn mode normal          back to normal
  cairn dump                 send the whole journal to the serial port (the dashboard uses this)
  cairn clear yes            erase the journal ON THE RADIO (the tablet's copy stays)
  cairn time <seconds>       set the radio's clock (seconds since 1970); the dashboard does this automatically
  nova ...                   all NOVA commands

REPEATER AND COMMUNICATIONS HUB
The CAIRN radio is a companion: it sends and receives your messages, but it does not repeat other people's. The
repeating is done by the second radio in the kit (XIAO ESP32S3 running PULSAR), powered from the hub. Together they
are the hub: the companion carries your chat, check-ins and journal, and the repeater extends the range for everyone.

LIMITS
- The radio cannot see power-bank or tablet charge; the Power tab timers are reminders.
- Keep antennas apart and away from the USB hub. Check "stats-radio" noise floor with the repeater on and off.
- A mesh radio is a backup, not a replacement for 911, a phone or a satellite messenger.
