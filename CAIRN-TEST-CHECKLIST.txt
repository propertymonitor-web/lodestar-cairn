LODESTAR CAIRN - HARDWARE TEST CHECKLIST (Ver. 1.3.0, beta)
By Wolf Reactive Systems (WRS). Nothing in CAIRN has run on real hardware yet. Work through this at home, then once in the open.
Write down anything that does not match. Heltec V4 R2 only.

A. FLASH THE COMPANION (Heltec V4 R2)
 1. Download firmware-merged.bin from the latest cairn release.
 2. flasher.meshcore.io -> Custom Firmware -> flash it. Use the Bluetooth (BLE) build.
 3. Pass: the radio boots and the screen shows CAIRN.

B0. SCREEN
    Pass: the boot splash shows the emblem on the left and LODESTAR / CAIRN / WRS / Ver. 1.3.0 on the right, and stays up for 5 seconds.
    Pass: the first page after Home is CAIRN STATION with your ID. Pressing Enter (or holding the button) shows
    "Check-in sending" and the check-in appears in the log.

B. STATION ID
 4. In the dashboard Console (or a serial console) type:  cairn
    Pass: it prints LODESTAR CAIRN 1.3.0  ID LC-xxxxxxxx (8 characters).
 5. Write the ID down. Reboot the radio (cairn is not needed: use the button or unplug/replug). Type  cairn  again.
    Pass: the SAME ID.
 6. Pass: the ID uses no I, O, 0 or 1.

C. DASHBOARD ON THE TABLET (do this once with internet)
 7. Open the dashboard page in Chrome (version 148+), add it to the Home screen. Switch Wi-Fi off and reopen it.
    Pass: it still opens.
 8. Plug the radio into the hub, hub into the tablet. Press Connect radio, pick the radio.
    Pass: status shows Live, the ID appears at the top, the radio clock is set.
    If Connect fails: unplug/replug; close other USB apps; note the exact message.
 9. Press Practice (with the radio disconnected) to confirm the pages work without a radio.

D. THE KIT TOGETHER
10. Connect the MeshCore app by Bluetooth to the companion at the same time as the dashboard on USB. Pass: both work.
11. Power the XIAO ESP32S3 repeater (PULSAR) from the hub. Keep its antenna at least an arm's length from the companion's antenna.
12. Radio noise check: on the companion type  stats-radio  with the repeater OFF, then ON. Note the noise floor both times.
    Pass: noise floor does not rise by more than a few dB. If it does, move the antennas apart or away from the hub.

E. CHECK-IN
13. Go outside with sky view, wait for a GPS fix (Station page shows fix and satellites).
14. Home -> I'M OK. Pass: the Check-ins list shows your own ID and position; the Log shows a "Check-in sent" line.
15. With a second radio on the same channel, check it receives:  LC-xxxxxxxx Reporting at: lat,lon
    With no fix the text must read:  ... Reporting at: no GPS fix

E2. CHAT
    a. Chat tab: pick Public, type a message, press Send (or Enter). Pass: a second radio on the channel receives it, and
       your message appears on the right of the conversation.
    b. Have the second radio reply. Pass: the reply appears in the same conversation and a red number shows on the Chat tab.
    c. Start a direct message with a person who has advertised. Pass: it arrives (they must be in the radio's contacts;
       if not, the dashboard shows "NOT sent" - note this).
    d. Type 141 characters. Pass: Send is disabled.

F. JOURNAL (store everything)
16. Let it run 30 minutes near other nodes. Pass: Log shows adverts and messages. Press Download CSV and Download JSON lines, open them.
17. Unplug and replug the radio. Press Reload from the radio. Pass: the log is still there (no duplicates).
18. Reboot the tablet. Pass: the Log still holds everything (kept in the browser).

G. REACHABLE BANNER AND DISASTER MODE
19. Near a repeater: banner REACHABLE. Take the repeater away or go out of range: banner turns red NO REPEATER HEARD and shows the last usable repeater.
20. Home -> DISASTER. Pass: "The radio is in DISASTER mode"; screen goes off sooner; quiet hours off. Press STANDARD to go back. Reboot the radio: the mode is the same afterwards.

H. OFFLINE MAP
21. At home on Wi-Fi: Map tab -> choose a region -> Download -> Load a map file.
22. Switch Wi-Fi off. Pass: the map shows from the offline file; your position and nodes are drawn.

I. KEYBOARD
23. With the physical keyboard attached: no on-screen keyboard appears when you tap a box. Tap the keyboard icon: it appears for that box.

J. POWER
24. Power tab: set each power bank's hours, press Fully charged / started now. Pass: countdown runs. Tablet battery shows.

L. NEW IN 1.1.0 (do these outdoors with a second radio listening on Public)
26. Splash: reload the dashboard on the tablet. Pass: the CAIRN splash fills the screen with nothing cut off; a tap skips it.
27. HELP: Home -> I NEED HELP -> NO. Pass: nothing sent. Again -> YES. Pass: the second radio receives
    "LC-xxxxxxxx NEEDS HELP at: lat,lon", then again after the help interval (Power -> Help call repeats every).
    Cancel: Pass: the second radio gets "Reporting at:", and the Home button returns to I NEED HELP.
28. HELP on the radio's screen: go to the HELP page. Hold once: "SEND HELP CALL?". Wait 6 seconds: back to normal (no call).
    Hold twice within 5 seconds: the call starts. Hold again: cancelled.
29. A second radio sends HELP: Pass: the dashboard shows the red alert with sound, distance and direction; Show on map
    centers the map on the red dot; Got it clears the alert.
30. STATUS and MARK: tap Need water, then Mark -> Hazard. Pass: the second radio receives
    "STATUS NEED WATER at:" and "MARK HAZARD at:"; the other dashboard lists them on People and on the map.
31. Channels: Chat -> Channels. Add "#test" (open). Pass: it appears; a MeshCore app channel "#test" can read and write
    to it. Make a private channel; Show key; add it on a second CAIRN with name + key; messages pass. Remove it: Pass: it is
    gone, and Public has no Remove button. Reboot the radio: the channels are still as left.
32. POWER, Standard: Power tab. Pass: about 630 mW (setting 22) with a 2 dBi antenna. Enter antenna 9 -> Pass: lower setting
    (14, about 26 dBm for 9 dBi). Measure with a power meter if you have one: write the real figure down. Heltec rates the
    board 28 +/- 1 dBm; if the measured power is above 30 dBm into the antenna the limit is NOT met: stop and report.
33. POWER, Disaster: switch to DISASTER with the battery below 25%. Pass: power stays at full. Switch back to STANDARD:
    Pass: power drops to the saver setting while the battery is below 25% and returns above 35%.
34. Low battery: run the radio on its battery until 15%. Pass: one "LOW BATTERY 15%" message; no repeats.
35. Automatic I'M OK: Power -> Automatic I'M OK every 15 minutes. Pass: check-ins arrive about every 15 minutes, and stop
    while a help call is running.
36. Power calculator: enter your power bank, tablet and solar figures. Pass: the answer is plausible against a real
    run (note the real hours for the first power bank).
37. Sending at full power with the real hub and power bank: send 10 messages in a row. Pass: the radio does not reboot. If
    it does, the hub or cable cannot supply the burst: change it.
38. Field guide: Guide tab on the tablet. Pass: it is readable at arm's length; Print or save as PDF works; the quick-start
    card (CAIRN-Quick-Start-Card.pdf) fits one page. Give the kit and the quick-start card to someone who has never used it:
    Pass: they send I'M OK and a help call (to a test channel) without help.

K. 100% OFFLINE RUN
25. Turn Wi-Fi and mobile data OFF. Repeat steps 8, 14, 16, 19. Pass: everything works with no internet.

M. NEW IN 1.2.0: THE CAIRN STATION TABLET APP (needs the 1.3.0 firmware on the companion; test with the real tablet, radio and repeater)
39. Install cairn-station-1.3.0.apk. Pass: Android installs it after the "unknown apps" prompt; the app opens and shows the splash, then the Wi-Fi step.
40. Wi-Fi step: press Skip. Pass: goes to the Repeater step. Repeat with Wi-Fi connected: Pass: shows Connected and moves on by itself after about 2 seconds.
41. Repeater step with the repeater's USB cable plugged in: press Connect, tap Allow. Pass: shows Connected; Continue works. With nothing plugged in: Pass: Continue stays grey.
42. Companion step: Find radios. Pass: the radio's name appears. Connect, type the PIN from the radio's screen. Pass: Connected, and "Open the dashboard" works. The step cannot be passed without it.
43. Pass: the station ID (LC-xxxxxxxx) appears in the header within a few seconds, and the Station screen fills in (this proves the Bluetooth text link works).
44. Press I'M OK. Pass: a second radio on Public hears the check-in.
45. Unplug the repeater cable. Pass: after about 10 seconds the Repeater step returns. Plug it back: Pass: it reconnects and the steps close.
46. Switch the companion radio off. Pass: the Companion step returns after about 10 seconds; switching it on lets Connect work again.
47. Station screen, Repeater card: Ask for status. Pass: the repeater's text appears. Files screen: Pass: a journal-DATE.log and repeater-DATE.log are listed and can be viewed.
48. With Wi-Fi: Online screen, Get ready now. Pass: weather, earthquakes and updates fill in; Ask Gemini is enabled and opens Gemini. Turn Wi-Fi off: Pass: Ask Gemini turns grey and the last weather stays, marked with its age.
49. Map screen: choose a region, Download. Pass: it downloads to the tablet, appears in the list, and shows the map with Wi-Fi OFF.
50. Press Home and then reopen CAIRN Station. Pass: the links are still connected. Set it as the Home app (Settings > Apps > Default apps): Pass: after a restart the tablet opens into CAIRN.

Report back: which steps passed, which failed, and exact messages. Mesh radio is a backup, not a replacement for 911 or a phone.
